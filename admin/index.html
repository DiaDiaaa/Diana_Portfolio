仅你授权的账号可以发布。令牌只在本次页面打开期间使用，刷新后需要重新连接。

第一次使用：如何获取授权令牌
  1. 创建 Fine-grained token ↗，选择一个有效期。
  2. Repository access 选择 Only select repositories → Diana_Portfolio。
  3. Repository permissions 中将 Contents 设为 Read and write，其余保留默认。
  4. 生成后复制到下方。不要把令牌发给别人。

尚未连接。可以先浏览授权说明。

支持 JPG / PNG / WebP。自动缩至最长边 2000px，并去除照片定位元数据；第一张就是封面。iPhone HEIC 请先导出为 JPG。每篇最多 40 张。
