# 摄影与日常手记

入口：`journal.html`。每篇使用 `journal.html?post=固定ID`，可独立分享。

## 发布内容

1. 把照片放到 `img/` 下的相册目录。
2. 在 `data/journal.json` 新增一项。`id` 必须唯一且发布后保持不变（留言按 ID 归档）。
3. `kind` 填 `photography` 或 `plog`；填写 `title`、`subtitle`、`note`。
4. `images` 每项填写 `src`（相对网站根目录）和 `alt`（照片描述）。第一张为封面。
5. 提交到 GitHub 并部署。当前三篇是用已有仓库照片整理的初始相册，文字为图片描述，未添加虚构日期或地点。

## 免登录留言：待开通

当前未配置服务，因此页面明确显示“留言区准备中”，没有伪提交或本地假留言。
前端已准备 Waline 接入，昵称必填、无需账号、关闭图片上传和表情搜索。每篇有独立的 `/journal/<id>` 留言路径。

开通步骤：

1. 按官方指南部署你自己的 Waline 服务和数据库：https://waline.js.org/en/guide/get-started/
2. 部署后立即在服务的 `/ui/register` 注册管理员（官方规则：首个注册账号成为管理员）。
3. 配置服务端审核、防刷间隔、来源域名限制；先审核再公开，限制到实际网站域名。以 https://waline.js.org/en/reference/server/env.html 的当前设置为准。数据库凭据只放服务端。
4. 在 `js/journal-config.js` 填写公开的 HTTPS `serverURL`。客户端版本固定在该文件，升级时同时核对 JS/CSS。
5. 上线前用两个不同浏览器验证：访客提交、审核后可见、回复、不同文章隔离、刷新后保留、连续提交限制。临时测试域名通过验证后从允许列表删除。

当前验证范围只包含页面、相册、路由、灯箱与未配置服务时的状态；没有真实服务器，不能验证提交、持久化或防垃圾配置。
